# منيو Curio + صفحة تعديل الأسعار

مشروع موقع ثابت (من غير سيرفر): المنيو للزباين + صفحة أدمن لصاحب المكان يعدّل منها **الأسعار بس**.
البيانات متخزنة في Supabase (مجاني للبداية).

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | المنيو للزباين (الافتتاحية + الأقسام + البحث). بيقرا الأسعار من Supabase |
| `admin.html` | صفحة الأونر: تسجيل دخول، تعديل الأسعار، تعديل جماعي بنسبة أو مبلغ مع Undo |
| `config.js` | رابط Supabase والمفتاح العام (الملف الوحيد اللي بتغيّره لكل عميل) |
| `schema.sql` | بيعمل الجداول والصلاحيات |
| `seed.sql` | بيحمّل منيو Curio الحالي (11 قسم، 75 صنف) |
| `starter-menu.js` | نسخة احتياطية من المنيو لو الاتصال فشل |

## التركيب (حوالي 15 دقيقة)

1. **مشروع Supabase:** ادخل supabase.com وسجّل، واعمل New project (اختار منطقة قريبة وباسورد قاعدة بيانات واحفظه).
2. **الجداول:** من القائمة اليسار افتح **SQL Editor** → New query → الصق محتوى `schema.sql` → Run. بعدها نفس الخطوات مع `seed.sql`.
3. **حساب الأونر:** من **Authentication → Users → Add user → Create new user**، حط إيميل وباسورد الأونر وفعّل Auto Confirm.
4. **اقفل التسجيل العام:** من **Authentication → Sign In / Providers** عطّل **Allow new users to sign up**، عشان محدش غير الأونر يقدر يعمل حساب.
5. **المفاتيح:** من **Project Settings → API** انسخ **Project URL** و **anon public key** والصقهم في `config.js`.
   لا تحط `service_role` key في أي ملف أبدًا.
6. **النشر:** ارفع المجلد كله على استضافة ملفات ثابتة: Netlify Drop (سحب وإفلات)، أو Cloudflare Pages، أو GitHub Pages، أو Vercel.
   - المنيو: `https://دومينك/` (أو `/index.html`)
   - الأدمن: `https://دومينك/admin.html`
7. **QR:** اعمل QR لرابط المنيو وطبعه للترابيزات.
8. **اختبار:** ادخل `admin.html` بحساب الأونر، غيّر سعر صنف، وافتح المنيو وتأكد إنه اتغيّر.

## الأونر بيعمل إيه

- يفتح `admin.html` من موبايله ويسجل دخول (بيفتكره بعد كده).
- يفتح القسم، يكتب السعر الجديد، ويضغط برّه الخانة. بيتحفظ لوحده والمنيو بيتحدّث فورًا.
- **Bulk change:** زيادة أو نقص كل الأسعار أو قسم واحد بنسبة أو مبلغ، مع تقريب لأقرب 5 مثلًا، ومعاينة قبل التنفيذ، وزرار **Undo**.

## الأمان

- الزباين يقدروا **يقروا** المنيو بس.
- الحساب المسجّل (الأونر) يقدر يعدّل عمود **`prices`** بس. ده متظبط في قاعدة البيانات نفسها (`grant update (prices)`)، فحتى لو حد عرف الباسورد مايقدرش يمسح أصناف أو يغيّر الأسماء.
- لتغيير الأسماء أو إضافة وحذف أصناف: من **Table Editor** في Supabase (انت كمطوّر).

## ملاحظات مهمة

- على الخطة المجانية Supabase بيوقف المشروع لو مفيش أي نشاط لمدة أسبوع تقريبًا (راجع الشروط الحالية). لو اتوقف، المنيو بيعرض آخر نسخة محفوظة في متصفح الزبون، أو النسخة الاحتياطية، يعني ممكن تظهر أسعار قديمة. الحل: خطة Pro للعميل، أو اتأكد إن المنيو بيتفتح باستمرار.
- المشروع اتجرّب على نسخة محاكية لـ Supabase API، **مش على مشروع Supabase حقيقي**. اعمل اختبار الخطوة 8 مرة واحدة بعد التركيب.
- لو عندك عمود `available = false` على صنف من Table Editor، المنيو بيعرضه "Sold out" بسعر مشطوب.

## لبراند جديد

1. غيّر اللوجو والغلاف والرسمة والألوان والاسم في `index.html` (اطلبهم مني بنفس البروموت).
2. عدّل `starter-menu.js` و`seed.sql` بأصناف العميل (أنا بولّدهم من ملف المنيو).
3. مشروع Supabase جديد لكل عميل، وكرر خطوات التركيب.
